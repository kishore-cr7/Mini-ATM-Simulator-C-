# Mini-ATM-Simulator-C++-      

Mini ATM Simulator (C++)

Mini ATM Simulator is a console-based application developed using C++ as part of the
19IT251 – Object Oriented Programming using C++ Laboratory.

This project simulates the basic functioning of an Automated Teller Machine (ATM)
by allowing users to securely access bank accounts and perform common banking
operations through a menu-driven interface.

-----------------------------------------------------------------------

Project Overview

The objective of this mini project is to design and implement a simple and
user-friendly ATM system using Object-Oriented Programming principles in C++.
The system provides a realistic banking experience while maintaining clarity
and simplicity for academic purposes.

-----------------------------------------------------------------------

Key Features

- Account creation with user details
- Secure login using PIN authentication
- Savings account support
- Cash deposit and withdrawal
- Minimum balance validation
- Balance enquiry
- Fund transfer between multiple accounts
- Transaction receipt generation with date and time
- File handling for persistent storage of account information
- Optional detailed receipt after money transfer

-----------------------------------------------------------------------

Object Oriented Design

The project applies the following Object-Oriented Programming concepts:

- Encapsulation of account data and operations within classes
- Abstraction using a menu-driven user interface
- Inheritance to allow extensibility of account types
- Polymorphism for handling multiple account objects
- Modularity for easy understanding and maintenance
